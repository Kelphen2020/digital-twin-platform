# P41.0 变更（概览柱状图随窗口自适应）

## `GET /api/tenants/{id}/overview?window=…` 新增字段

```json
"series": [
  { "bucket": "2026-11-19T06:30:00Z", "count": 3 },
  { "bucket": "2026-11-19T06:35:00Z", "count": 0 }
],
"bucket_seconds": 300
```

- `series`：所选窗口内的事件直方图，**连续**填充（空桶计 0），最多 400 个桶。
- `bucket_seconds`：桶宽，按窗口自动选择以保证柱子数量在 8–25 之间：

| window | 桶宽 | 柱子数 |
|---|---|---|
| `1h` | 5 分钟 | 13 |
| `6h` | 30 分钟 | 13 |
| `24h` | 1 小时 | 25 |
| `7d` | 1 天 | 8 |

- `recent_hourly` 保留（固定近 24 小时小时桶），仅用于兼容旧客户端。

## 前端

- 柱状图改为消费 `series`，标题显示「事件分布（1 小时 / 6 小时 / 24 小时 / 7 天）」。
- 柱子数 > 20 时自动切换密集模式（标签竖排、间距收紧），避免 24 小时窗口标签重叠。
- 桶标签按桶宽格式化：分钟/小时窗口显示 `HH:mm`，天窗口显示 `MM-DD`。
- **修复**：此前切换窗口只更新了 KPI 环比，柱状图仍停留在初次的 24 小时数据（`fetchTenantOverview` 未传窗口参数）。
