# P40.0 变更（运维概览时间窗口与趋势）

## `GET /api/tenants/{id}/overview?window=1h|6h|24h|7d`

- `window` 缺省或非法值 → 回退 `24h`（不报错，保证面板始终可用）。
- 响应新增 `window` 块：

```json
"window": {
  "duration": "24h",
  "from": "2026-11-17T00:00:00Z",
  "to": "2026-11-18T00:00:00Z",
  "current": 42,
  "previous": 30
}
```

`current` 为当前窗口内事件数，`previous` 为**紧邻的等长上一窗口**事件数，用于环比。

## 前端

- 「运维概览」标题栏新增时间窗口切换：**1 小时 / 6 小时 / 24 小时 / 7 天**，切换即重新拉取（保留 30 秒自动刷新）。
- 「事件」KPI 显示所选窗口计数与环比：`▲ +12（40%）vs 上期 30`；上升为红色、下降为绿色、持平时显示「持平」。
- KPI 可点击跳转：待处理工单 → 工单页、巡检进行中 → 值班页、导出任务 → 租户页（支持键盘 Enter）。
- 版本标记同步至 **P40.0**。
